# requires huggingface-hub >=1.5,<2.0, which intersects gradio's range.
# Verified against PyPI metadata, not guessed.
#
# NOTE: the notebooks still run transformers 4.x on Colab (root
# requirements.txt). src/rag_pipeline.py is written to work on both — it uses
# `dtype=` and the stable Auto*/BitsAndBytesConfig surface.
